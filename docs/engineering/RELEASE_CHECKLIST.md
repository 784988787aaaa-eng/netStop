# قائمة التحقق للإطلاق والاعتماد: NetBalancer Android
**ملف:** `docs/engineering/RELEASE_CHECKLIST.md`  

---

## بنود التدقيق والجاهزية (20 بنداً إلزامياً)

- [x] **1. سلامة البناء:** اجتياز `compile_applet` بدون أخطاء.
- [x] **2. اجتياز الاختبارات:** 13 اختباراً محلياً ووحدة وRobolectric بنسبة نجاح 100%.
- [x] **3. سلامة التوقيع:** الحفاظ الكامل على `signingConfigs` في `app/build.gradle.kts`.
- [x] **4. تزامن هوية التطبيق:** تطابق اسم التطبيق "NetBalancer" في `metadata.json` مع `strings.xml`.
- [x] **5. حماية أذونات Android:** طلب الأذونات الصريحة (`INTERNET`, `VIBRATE`, `ACCESS_NETWORK_STATE`, `POST_NOTIFICATIONS`) في `AndroidManifest.xml`.
- [x] **6. خلو الكود من الأسرار والمفاتيح:** لا توجد مفاتيح مسربة في الكود، مع استخدام Secrets plugin.
- [x] **7. خلو البيانات من المحاكاة الوهمية:** إلغاء قص السرعات الاصطناعي والاعتماد على عدادات النواة.
- [x] **8. دقة حساب الاستهلاك اليومي:** احتساب فوارق الجلسات بدلاً من عدادات إقلاع الهاتف.
- [x] **9. سلامة دورة حياة الـ VPN:** إدارة حالات التشغيل بـ 7 أطوار واضحة (`EngineUiState`).
- [x] **10. أبعاد مساحات اللمس (Accessibility):** جميع العناصر التفاعلية بارتفاع لا يقل عن 48dp والزر الرئيسي 56dp+.
- [x] **11. الدعم الكامل للغة العربية (RTL):** محاذاة سليمة، ومصطلحات تقنية متسقة، وأيقونات موجهة.
- [x] **12. أداء قاعدة البيانات:** تنفيذ استعلامات Room على خيوط الخلفية (`Dispatchers.IO`).
- [x] **13. إدارة الذاكرة:** تنظيف دوري للتدفقات الخاملة، وحصر سجل الأحداث عند 250 حدثاً.
- [x] **14. دقة اتجاه الحزم:** فحص عنوان IP الوجهة لتحديد التنزيل والرفع.
- [x] **15. ذرية تحديث الحصص:** الحفاظ على تواريخ بداية الفترات عند تقدم الاستهلاك.
- [x] **16. معالجة رفض الأذونات:** تقديم توجيه واضح للمستخدم عند رفض إذن الـ VPN أو الإشعارات.
- [x] **17. عدم استنزاف المعالج:** استخدام `StateFlow` مع مهلات اشتراك 5 ثوانٍ (`WhileSubscribed(5000)`).
- [x] **18. التوافق مع Android 13+ و 14+:** دعم متطلبات Foreground Service الخاصة بالـ VPN مع `FOREGROUND_SERVICE_SPECIAL_USE`.
- [x] **19. جاهزية مسار CI:** تهيئة وتحديث سير عمل GitHub Actions لبناء APK موقع بنجاح.
- [x] **20. استكمال الوثائق الهندسية:** توثيق كامل في مجلد `docs/engineering/`.
