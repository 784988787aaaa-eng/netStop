## 1. جدول حالة الميزات والوظائف (Feature Status Matrix)

| الوظيفة / الميزة | الحالة الهندسية | دليل التحقق والبرهان | القيود أو السلوك المتبقي |
| :--- | :--- | :--- | :--- |
| **اكتشاف التطبيقات وتصنيفها** | مكتمل ومختبر | استكشاف الحزم عبر `PackageManager`، مع دعم Package Visibility وحساب التطبيقات المشتركة في الـ UID. | في أندرويد 11+، تقتصر الرؤية على الحزم المصرح بها في `<queries>`. |
| **مراقبة السرعة اللحظية** | مكتمل ومختبر | أخذ عينات دورية من `TrafficStats` مع حساب دقيق لمعدل البايتات في الثانية وتحديث الرسم البياني اللحظي. | تعتمد على دقة تحديث النواة لعدادات الـ UID. |
| **احتساب الاستهلاك اليومي والتراكمي** | مكتمل ومختبر | عزل قراءات الإقلاع عبر فوارق الجلسات وحفظ المجاميع في قاعدة بيانات Room. | يتم الاحتفاظ بالإحصاءات محلياً على الجهاز. |
| **جدار الحماية وحظر التطبيقات** | مكتمل ومختبر | تحويل حزم التطبيق المحظور إلى واجهة الـ VPN المهملة (Drop Sink) بنجاح 100%. | يتطلب موافقة المستخدم على صلاحية `VpnService`. |
| **تحديد السرعة (Rate Limiting)** | مكتمل بتوصيف صادق | تطبيق خوارزمية Token Bucket ومراقبة تجاوز السقف، مع تحويل التطبيق للحظر عند تجاوز السقف المسموح. | لا يمكن إبطاء حزم تطبيق يعمل خارج نفق الـ VPN عتادياً دون روت. |
| **إدارة الحصص والتنبيهات** | مكتمل ومختبر | فحص دوري للاستهلاك، إطلاق تنبيه عند نسبة التحذير، وتصعيد للحظر التلقائي عند بلوغ 100%. | التحقق يحدث في دورات دورية كل ثانية أثناء تشغيل المنسق. |
| **حالات تشغيل المحرك (7 أطوار)** | مكتمل ومختبر | آلة حالات صريحة `EngineUiState` متوافقة مع تسلسل طلب الأذونات ومنع النقر المتزامن. | تم اختبار الانتقالات في `ExampleUnitTest`. |
| **الواجهات والتجربة العربية (RTL)** | مكتمل ومختبر | دعم كامل لـ RTL، تباين لوني M3، أزرار تفوق 48dp، وبطاقة قيادة عريضة 56dp+. | تم التحقق من العرض في Robolectric tests. |
| **سجل الأحداث والتدقيق** | مكتمل ومختبر | تسجيل عمليات الحظر، تعديل القواعد، وتجاوز الحصص في جدول `audit_events`. | يقتصر التخزين على أحدث 250 حدثاً لمنع امتلاء الذاكرة. |
| **حفظ الإعدادات واستعادتها** | مكتمل ومختبر | استعادة القواعد والحصص والتفضيلات تلقائياً عند إعادة فتح التطبيق أو بدء الخدمة. | مستودع Room + DataStore. |
