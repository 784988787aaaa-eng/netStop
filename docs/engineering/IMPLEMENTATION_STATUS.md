## 1. جدول حالة الميزات والوظائف (Feature Status Matrix)

| الوظيفة / الميزة | الحالة الهندسية | دليل التحقق والبرهان | القيود أو السلوك المتبقي |
| :--- | :--- | :--- | :--- |
| **اكتشاف التطبيقات وتصنيفها** | مكتمل ومختبر | استكشاف الحزم عبر `PackageManager` + تحديث تلقائي فوري عبر `BroadcastReceiver` عند تثبيت أو حذف أو تحديث أي تطبيق (`NB-012`). | في أندرويد 11+، تدعم صلاحية `QUERY_ALL_PACKAGES` و `<queries>` اكتشاف الحزم. |
| **مراقبة السرعة اللحظية** | مكتمل ومختبر | أخذ عينات دورية من `TrafficStats` بدون `maxOf()` لإخفاء الفروق، مع عرض حركة النظام غير المنسوبة بصراحة وتمييز `UNAVAILABLE` (`NB-009`). | تعتمد على دقة تحديث النواة لعدادات الـ UID. |
| **احتساب الاستهلاك اليومي والتراكمي** | مكتمل ومختبر | عزل قراءات الإقلاع، ومعالجة تصفير عدادات النواة (`currentRx < lastRx`) دون فقدان الاستهلاك المتراكم (`NB-010`). | يتم الاحتفاظ بالإحصاءات محلياً على الجهاز. |
| **جدار الحماية وحظر التطبيقات** | مكتمل ومختبر | تحويل حزم التطبيق المحظور إلى واجهة الـ VPN المهملة (Drop Sink) مع تمييز الحالة المحفوظة عن النافذة عبر `RuleEnforcementState` (`NB-011`). | يتطلب موافقة المستخدم على صلاحية `VpnService`. |
| **تحديد السرعة (Rate Limiting)** | مكتمل بتوصيف صادق | تطبيق خوارزمية Token Bucket ومراقبة تجاوز السقف، مع تحويل التطبيق للحظر عند تجاوز السقف المسموح. | لا يمكن إبطاء حزم تطبيق يعمل خارج نفق الـ VPN عتادياً دون روت. |
| **إدارة الحصص والتنبيهات** | مكتمل ومختبر | فحص دوري للاستهلاك، إطلاق تنبيه عند نسبة التحذير، وتصعيد للحظر التلقائي عند بلوغ 100%. | التحقق يحدث في دورات دورية كل ثانية أثناء تشغيل المنسق. |
| **حالات تشغيل المحرك (7 أطوار)** | مكتمل ومختبر | آلة حالات صريحة `EngineUiState` متوافقة مع تسلسل طلب الأذونات ومنع النقر المتزامن. | تم اختبار الانتقالات في `ExampleUnitTest`. |
| **الواجهات والتجربة العربية (RTL)** | مكتمل ومختبر | دعم كامل لـ RTL، المصطلحات العربية المعيارية (القسم 11)، 7 خيارات فرز و 6 خيارات تصفية، وملخص القواعد والحصص والتنبيهات في الرئيسية (`NB-013`). | تم التحقق من العرض في Robolectric tests. |
| **سجل الأحداث والتدقيق والتشخيص** | مكتمل ومختبر | تسجيل الأحداث في `audit_events` + لوحة تشخيص تعرض حالة مصدر الإحصاءات، آخر خطأ، آخر نجاح ومزامنة، ومصفوفة توافق Android 10–14+. | يقتصر التخزين على أحدث 250 حدثاً لمنع امتلاء الذاكرة. |
| **حفظ الإعدادات واستعادتها** | مكتمل ومختبر | استعادة القواعد والحصص والتفضيلات تلقائياً عند إعادة فتح التطبيق أو بدء الخدمة. | مستودع Room + DataStore. |

## 2. ملخص التحقق الآلي
- **تجميع الكود:** ناجح (`compile_applet`).
- **اختبارات الوحدة:** 13 اختباراً ناجحاً (`ExampleUnitTest`).
- **اختبارات Robolectric:** اختباران شاملان لواجهة Compose وقاعدة بيانات Room ناجحان (`ExampleRobolectricTest`).
- **مجموع الاختبارات:** 15 اختباراً، نسبة النجاح 100%.
